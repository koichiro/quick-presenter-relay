# Security policy

## Supported versions

Security fixes target the latest published 1.x release of these packages:
- `quick-presenter-relay`
- `quick-presenter-relay-core`
- `quick-presenter-audience-web`

Upgrade older 1.x versions to the latest patch. Pre-release versions and modified
builds are outside this support policy.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/koichiro/quick-presenter-relay/security/advisories/new)
to send a private report. Include the affected package/version, expected and actual
behavior, and a minimal reproduction using synthetic data. Never include tokens,
real audience messages, private presentation data or production identifiers.

Do not report suspected security vulnerabilities in public issues or pull requests.
For ordinary bugs and feature requests, use the public issue tracker. Coordinate
public disclosure in the private report after a fix or mitigation is available.
